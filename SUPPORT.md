# Support

RuntimeTruth is a pre-release open-source project maintained on a best-effort basis.

## Community support

Use GitHub issues for reproducible bugs and focused feature requests once the repository is public.

There is currently:

- no paid support plan
- no guaranteed response time
- no uptime commitment
- no SLA
- no hosted RuntimeTruth service to operate on a user's behalf

A lack of maintainer response does not imply that a configuration or runtime state is safe.

## Before filing an issue

Include the minimum information needed to reproduce the problem:

- RuntimeTruth version or commit
- operating system and Python version
- inspected runtime/version when relevant
- the exact command used
- a minimal sanitized snapshot or error message when necessary

Do not post secrets, private prompts/instructions, tokens or private infrastructure details.

## Security reports

Do not use a normal public issue for vulnerabilities or sensitive security findings. Follow [SECURITY.md](SECURITY.md).

## Commercial support

No commercial support offering is currently provided. If that changes later, it will be documented separately and will not retroactively change the terms of the open-source MIT-licensed releases.
